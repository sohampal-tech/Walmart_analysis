# Walmart Sales Analysis — End-to-End Python + SQL Project
An end-to-end data analytics project that uses Python to prepare Walmart sales data, stores the cleaned dataset in a relational database, and uses SQL queries to answer business questions about sales, payments, ratings, branches, and transaction patterns.

# Tools and technologies

- Python — data processing
- Pandas — data inspection and cleaning
- Jupyter Notebook / IPython — interactive analysis
- SQLAlchemy — Python-to-database connection
- PyMySQL — MySQL driver for Python
- MySQL / MySQL Workbench — database storage and SQL analysis
- Kaggle — dataset source
# Business questions explored

The SQL analysis can answer questions such as:
1. Which payment methods are used, and how many transactions and items are associated with each?
2. Which category has the highest average rating in each branch?
3. What is the busiest weekday for each branch by transaction count?
4. How many items are sold through each payment method?
5. What are the minimum, maximum, and average category ratings in each city?
6. What is the total estimated profit for each category?
7. What is the most common payment method in each branch?
8. How many transactions occur during morning, afternoon, and evening shifts?
9. Which branches show the largest revenue decrease between two selected years?

# Results and Insights
- Sales Insights: Key categories, branches with highest sales, and preferred payment methods.
- Profitability: Insights into the most profitable product categories and locations.
- Customer Behavior: Trends in ratings, payment preferences, and peak shopping hours.
